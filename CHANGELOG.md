# Changelog

All notable changes to SiteLens will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Initial project structure with `apps/extension`, `apps/dashboard`, and `apps/cli`.
- 58 stable, documented checks for browser-visible observations.
- Evidence Explorer for tracking provenance, coverage, and limitations.
- Wappalyzer-style Technology Profile with a local catalog of 75 technologies.
- CLI for browser-backed assessments, reporting, and policy validation.
- Developer Tools including fix recipes and CSP report-only rollout assistant.
- Local backup and restore capabilities with schema-1 migration support.

### Changed
- Shifted away from legacy root-level JavaScript prototype to the structured monorepo.
